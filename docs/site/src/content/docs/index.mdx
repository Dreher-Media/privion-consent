## See it in action

<Tabs>
<TabItem label="Vanilla JS">

```html
<!-- index.html -->
<script type="privion" privion-category="analytics"
  src="https://www.googletagmanager.com/gtag/js?id=G-XXX"></script>

<div privion-banner hidden>
  <p>We use cookies to improve your experience.</p>
  <button privion-reject-all>Reject all</button>
  <button privion-accept-all>Accept all</button>
</div>

<script type="module">
  import { createPrivionConsent } from '@privion-consent/core';
  import { initPrivionDom } from '@privion-consent/dom';

  const consent = createPrivionConsent({
    version: 1,
    categories: [
      { id: 'necessary', label: 'Necessary', required: true, defaultStatus: 'granted' },
      { id: 'analytics', label: 'Analytics' },
    ],
    googleConsentMode: { mode: 'advanced' },
  });

  initPrivionDom(consent);
</script>
```

## Why this library

<CardGrid>
  <Card title="Headless by default" icon="puzzle">
    Components emit `[privion-banner]` / `[data-privion-banner]` attributes and let your CSS take over. Opt into the bundled stylesheet for a working baseline.
  </Card>
  <Card title="Region-aware" icon="globe">
    Map ISO country codes to `opt-in` / `opt-out` defaults so EU / UK / CH visitors get the banner and the rest of the world doesn't — without shipping a geo database.
  </Card>
  <Card title="Google Consent Mode v2" icon="approve-check">
    Native support for `basic` and `advanced` modes with correct `default` / `update` sequencing. Returning visitors get `update` on init so their stored decision propagates to gtag immediately.
  </Card>
  <Card title="Late-injection safe" icon="rocket">
    A `MutationObserver` re-scans the DOM for tagged scripts, iframes, and visibility-keyed elements after the initial mount — works in SPAs, Astro islands, and any framework that hydrates async.
  </Card>
  <Card title="Backend sync" icon="cloud-download">
    POST every state change to your audit endpoint. Exponential backoff for 5xx and network errors, structured `BackendSyncError` for observability.
  </Card>
  <Card title="Pluggable storage" icon="setting">
    Cookie or localStorage out of the box. Plug a `ConsentStorageAdapter` for IndexedDB, React Native AsyncStorage, or a server-side store.
  </Card>
</CardGrid>

## What it isn't

To be clear about scope before you adopt:

- **Not a legal-text provider.** You write the banner copy and privacy policy.
- **No geo database.** You pass a region; we apply the rules.
- **Not an IAB TCF v2.2 CMP.** Privion doesn't implement the TCF protocol or register as an IAB CMP. If your site monetizes via Google Ad Manager / AdSense / programmatic display in the EU, you need a certified CMP — Privion isn't one and isn't planned to be. See [FAQ — Do I need TCF?](/guides/faq/#do-i-need-tcf-support).
- **Not an audit-log backend.** We `POST` decisions to *your* endpoint with retries; you store them.

The library provides the **mechanism**; legal determinations and infrastructure are on you. See [Compliance & scope](/reference/specification/#compliance-scope) for the GDPR / ePrivacy / TTDSG mapping.

## Why this library

<CardGrid>
  <Card title="Headless by default" icon="puzzle">
    The components emit `[privion-banner]` / `[data-privion-banner]` attributes and let your CSS take over. Opt into the bundled stylesheet for a working baseline, or ship your own.
  </Card>
  <Card title="Region-aware" icon="globe">
    Map ISO country codes to `opt-in` / `opt-out` defaults so EU / UK / CH visitors get the banner and the rest of the world doesn't — without shipping a geo database.
  </Card>
  <Card title="Google Consent Mode v2" icon="approve-check">
    Native support for `basic` and `advanced` modes with correct `default` / `update` sequencing. Returning visitors get `update` on init so their stored decision propagates to gtag immediately.
  </Card>
  <Card title="Late-injection safe" icon="rocket">
    A `MutationObserver` re-scans the DOM for tagged scripts, iframes, and visibility-keyed elements after the initial mount — works in SPAs, Astro islands, and any framework that hydrates async.
  </Card>
</CardGrid>
